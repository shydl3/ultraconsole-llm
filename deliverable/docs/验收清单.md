# 交付验收清单

在一台**干净的 Windows 11 + NVIDIA 机器**上逐项勾选。每项都要有实际输出，不接受“看起来正常”。

## 1. 环境

| # | 检查 | 方法 | 预期 |
|---|---|---|---|
| 1.1 | 显卡驱动 | `nvidia-smi` | 显示型号与驱动版本 |
| 1.2 | Docker | `docker version` | Client/Server 均有版本 |
| 1.3 | GPU 可见 | `诊断.bat` | 输出 GPU 型号，无报错 |
| 1.4 | 磁盘 | `诊断.bat` / 资源管理器 | 剩余 ≥ 30GB |

## 2. 安装

| # | 检查 | 方法 | 预期 |
|---|---|---|---|
| 2.1 | 镜像导入 | `启动.bat` 首次运行 | 提示导入完成 |
| 2.2 | 依赖安装 | `启动.bat` | 两个 venv 建好，无 pip 报错 |
| 2.3 | 权重下载 | `打开数据目录.bat` | `models\Qwen3-VL-2B-Instruct\config.json` 与 `model.safetensors` 存在 |
| 2.4 | YOLO 权重 | 同上 | `models\detect\yolo11m-pose.pt` 约 42MB |
| 2.5 | 健康检查 | `docker compose ps` | `app` 为 `healthy` |

## 3. 功能

| # | 检查 | 方法 | 预期 |
|---|---|---|---|

| 3.3 | 上传视频 | 语义分析页上传 5–10 分钟视频 | 进度到 100%，库中出现记录 |

## 4. 稳定性

| # | 检查 | 方法 | 预期 |
|---|---|---|---|

## 6. 已知不通过项的处理

- **NVENC 不可用**：预览转码会失败，但分析链路不受影响。记录为已知限制，并评估是否补软件回退。
- **Docker Desktop 未授权**：改用 Linux 服务器 + NVIDIA Container Toolkit，或走原生 Windows 方案。
- **内存不足**：按 `运维手册` 配置 `.wslconfig`，或改用 2B 模型（默认已是 2B）。
